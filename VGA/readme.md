4. simple text

each example have the design file and testbench file

for DE-Sim usage
1. copy-paste one folder in /DESim/demos/verilog/
2. rename the new folder to [new-folder]
3. place the design file (vga*.v) in /DESim/demos/verilog/[new-folder]/
4. place the testbench file (tb.v) in /DESim/demos/verilog/[new-folder]/tb/
5. run DE-Sim as usual
